# 空列删除与签字词保护设计决策

## 背景

在 signed Excel 输出时，工资表中可能出现完全无数据的空列。这些空列占用打印空间，影响输出整洁度。同时，部分空列中可能包含签字提示词（如"总经理签字"），删除时需要保护这些关键词不被丢失。

## 决策记录

### 1. 空列定义

**规则**: 某列所有数据单元格均为空，即视为空列。

包含两种情形:
- 整列所有单元格均为 None / 空值。
- 列中有非 None 单元格，但所有非 None 值均为签字提示词（无真实数据），也视为空列。删除前需将签字词右移到其他列保存。

### 2. 关键词保护

**规则**: 删除空列前，将列中的签字提示词右移到最近非空列的同一行单元格。

具体策略:
- 从当前列向右扫描，找到第一个包含真实数据（非关键词）的列作为目标列。
- 将关键词写入目标列的对应行。
- 若右侧不存在包含数据的列，则在列尾追加一个新列存放关键词。
- 操作完成后删除原空列。

这样保证签字提示词不因列删除而丢失，同时不覆盖已有数据。

### 3. 合并单元格

**规则**: 合并单元格由 openpyxl 的 `delete_cols` 自动调整合并范围，无需额外处理。

删除列时，openpyxl 会自动收缩受影响的合并单元格区域。开发者无需手动调整合并范围，也不需对合并单元格做特殊判断。

### 4. 关键词来源

**规则**: 签字关键词从 `payroll_sheet_config.json` 配置文件中提取，不硬编码在代码中。

提取来源包括三个部分:
- `sheet_filter.signatures.mandatory` 中的所有 key。
- `sheet_filter.signatures.optional` 中的所有 key。
- `text_normalization.rules` 中每条规则的 `source` 字段。

三者合并去重后作为完整的关键词集合。这样做的好处是关键词随着配置变化自动同步，不会出现代码与配置不同步的问题。

### 5. 制表人居右

**规则**: 制表人单元格对齐方式设为 `horizontal='right', vertical='center'`。

确保打印时制表人信息靠右对齐，符合财务表格的排版习惯。

## 影响范围

- 仅影响工资表 sheet 的处理流程，非工资表 sheet 不受影响。
- 不修改配置文件结构。
- 不改动其他模块。

## 相关文件

- `app/batch_processor.py`: 核心逻辑所在文件。
- `app/payroll_sheet_config.json`: 签字关键词配置来源。
